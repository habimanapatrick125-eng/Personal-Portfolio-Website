# Alex Rivera · Personal Portfolio Website

A responsive, multi-page personal portfolio website built with **HTML5**, **CSS3**, and **Bootstrap 5**.

## 🔗 Live Site
Once deployed via GitHub Pages: `https://yourusername.github.io/alexrivera-portfolio/`

## 📁 Pages
- `index.html` — Home: hero, highlights, featured projects
- `about.html` — Biography, education timeline, skills, interests
- `gallery.html` — Self-motivation video + photo gallery
- `contact.html` — Contact info, form, map, FAQ

## 🚀 Technologies
- HTML5 & CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts (Plus Jakarta Sans, Inter)

## 📦 Setup
1. Clone the repo
2. Open `index.html` in your browser
3. Or run `python -m http.server` for local server

## 🌐 Deployment (GitHub Pages)
1. Push all files to a public GitHub repo
2. Go to **Settings → Pages**
3. Choose `main` branch → `/root` → Save
4. Your site is live at `https://yourusername.github.io/repo-name/`
